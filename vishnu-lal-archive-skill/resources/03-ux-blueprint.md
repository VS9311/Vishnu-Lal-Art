# Vishnu Lal — Website Experience & UX Blueprint V1.0

## Purpose
The website is a **public entrance to the Vishnu Lal Archive**, not a conventional artist portfolio or ecommerce storefront.

## Experience Principle
**Encounter → Curiosity → Credibility → Access**

First make the visitor look, then wonder, then understand the seriousness of the practice, then provide a route toward acquisition or professional contact.

## Primary Users
- Private Collector
- Interior Designer / Architect
- Curator / Gallery / Institution
- General Art Audience

## Primary Journey
**Landing → Encounter → Explore Archive → Study Work → Understand Practice → Understand Artist → Request Access**

## Homepage
1. **The Encounter:** full-viewport selected work; minimal navigation; no immediate sales message; accurate proportions.
2. **The Proposition:** restrained introduction using the working central line and concise Archive explanation.
3. **Selected Corpus:** small number of major works; scale, sequence and whitespace rather than a thumbnail grid.
4. **The Practice:** material, mark-making, development, observation and artist voice.
5. **The Artist:** verified biography, development, mentors/formative context and present practice.
6. **Archive / Series:** bodies of work as chapters in a practice, not product categories.
7. **Access:** Private acquisition / Request catalogue / Arrange a viewing / Professional enquiry.
8. **Closing Field:** minimal identification and contact.

## Archive Experience
Two speeds of looking:
- **Fast Encounter:** large visual sequences with minimal metadata.
- **Slow Study:** open a work for its documentary record.

Avoid turning the Archive into a shopping catalogue.

## Work Page
Image → identification → material record → curatorial observation → availability → access.

Only public-facing information should appear.

## Archive Interaction
**Enter Archive → select series → encounter works → open fragment → return to corpus**

## Collector Journey
Discovery → Recognition → Investigation → Qualification → Private Contact → Acquisition.

The website facilitates the relationship rather than closing a high-value transaction like ecommerce.

## Interior Designer / Architect Journey
**Discover → Select → Assess → Enquire**

Make dimensions, orientation, material, availability, installation suitability, image quality and enquiry path easy to find without becoming a decor catalogue.

## Institutional Journey
**Encounter → Practice → Artist → Corpus → Documentation → Contact**

## Navigation
Primary:
**ARCHIVE / PRACTICE / ARTIST / ACCESS**

Keep the navigation minimal rather than corporate.

## Mobile
Artwork remains dominant; typography readable; metadata clear; transitions fast enough; navigation minimal. Preserve original artwork proportions rather than social-media-style cropping.

## Accessibility
Readable type, keyboard access, meaningful alt text, sufficient contrast, visible focus states, no hover-only information, clear forms.

## Conversion
Primary: **Private enquiry**
Secondary: Request catalogue, Request viewing, Professional enquiry, appropriate follow/updates.

Optimize for qualified contact, not email volume.

## Private Access Layer — Future
Password-protected collector room may contain unreleased works, complete availability, detailed dimensions, provenance, installation photographs, acquisition information and viewing arrangements.

## MVP Exclusions
No ecommerce checkout, public price tables, complex accounts, elaborate search, social-feed domination, hundreds of public artwork pages, artificial scarcity countdowns or excessive animation.

## MVP Page Map
1. Home / Encounter
2. Archive / Selected Corpus
3. Fragment / Individual Work
4. Practice
5. Artist
6. Access / Private Acquisition
7. Contact

## Success Test
The first five minutes should answer:
1. Who is Vishnu Lal?
2. What is distinctive about the practice?
3. Is there a coherent body of work?
4. Is it professionally presented?
5. How do I get closer if genuinely interested?
