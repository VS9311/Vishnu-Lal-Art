## 0. Data Governance

This file is a **content source**, not a design specification.

Antigravity must not invent, infer, normalize, rename, or embellish catalogue information.

### Hard rules

- Never invent artwork titles.
- Never invent dates.
- Never invent dimensions.
- Never invent provenance.
- Never invent exhibition history.
- Never invent quotations.
- Never turn visual observations into artist intent.
- Never convert a working identification into a public fact.
- If a field is not established, leave it blank or mark it `Not established`.
- Artwork images must be linked by verified archive ID.
- Presentation, layout and interaction belong to the website implementation; catalogue facts belong here.

---

## 1. Identifier Convention — IMPORTANT

The currently fetched Notion page for the Series II selected corpus uses identifiers in the form:

`VL-B-001` through `VL-B-012`.

The project direction has subsequently referred to the preferred website/archive convention as `VRB`.

**Do not silently rewrite the source identifiers.**

For the current implementation:

- Preserve the source catalogue identifier exactly in the archival record.
- If the website uses `VRB`, implement it as a deliberate display/alias layer.
- Do not create a second competing identifier system inside individual artwork records.
- Before public launch, establish one final canonical ID convention across Notion, filenames, JSON, URLs and the website.

# 2. Series II — Selected Corpus

Series II demonstrates a movement from isolated figure construction toward increasingly complex multi-form compositions in which the page itself becomes an active organizational field.

The twelve works below constitute the selected Series II corpus currently documented in Notion.
